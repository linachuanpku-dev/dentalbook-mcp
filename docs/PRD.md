# PRD：Dentalbook v5

| 项目 | 内容 |
|---|---|
| 状态 | 共享文献库第一版 |
| 用户 | 小范围口腔医生、研究者与可信管理员 |
| 交付形态 | 轻量 Web 文献库 + 通用 Agent 插件与开放 MCP |
| 当前里程碑 | Web 共享列表/下载/作者索引 + A 管理员 Fetch + B 用户上传 |

## 1. 问题与核心资产

医生的文献发现、全文获取、证据摘录、综述和引用回溯分散在多个工具中。通用 Agent 在语言生成上持续升级，但它本身不拥有 Dentalbook 的三项核心资产：

1. 经过配置和人工修订的作者身份与关系。
2. 可便捷抓取、共享但受控的论文目录与全文缓存。
3. 能把引用绑定到真实文件、页码和原句的完整性证明。

v5 的目标不是再造一个 Agent，而是把这些资产以稳定协议提供给不同 Agent 宿主。

## 2. 用户结果

### 医生

- 在固定 Web 地址或 Cursor、Codex、Claude 等 MCP 客户端中搜索同一私有论文目录。
- 清楚区分“题录存在”“中心有 PDF”“本地有 PDF”和“原句已精确定位”。
- 将论文加入本地笔记本，管理阅读状态、高亮、证据卡和综述。
- 点击引用先查看证据卡，再按需定位同一 SHA-256 PDF 的对应页。
- 浏览作者、机构、合作者、师承和团队关系，并看到关系来源与可信等级。
- 在宿主不支持 MCP Apps 时完成同样的文字版工作流。

### 管理员

- 通过隔离的管理 MCP 或最小 CLI 检查服务、维护令牌、备份、恢复和重建索引。
- 审阅可信用户提交的作者 changeset，并按 changeset 回滚。
- 管理全文的许可、同步限制、访问审计和下架。
- 用 Codex 或 Claude Code 测试插件和批量维护数据，而不依赖专用 GUI。

## 3. v1 范围

- 共享论文目录、受控全文缓存与缺篇抓取任务。
- 本地论文同步、笔记本、阅读状态。
- 高亮、证据卡、引用连接、引用审计和可信综述。
- 作者身份、机构、地理位置、合作者、师承与团队关系。
- 可信写入、changeset、审计、冲突检测、确认令牌和管理员回滚。
- 四个独立 MCP App：笔记本、引用、作者地图、作者关系图。
- 可独立访问的浅色 Web：文献列表、搜索、下载和基础作者索引。

## 4. 非目标

- 独立 Agent、自有聊天壳、Electron 或 DMG。普通 Web 数据界面属于产品入口，不包含自有模型会话。
- 控制 Codex 的固定右侧栏；宿主决定显示位置。
- PPT、全文翻译、成品社区、评论、公开运营和旧数据迁移。
- 宣称完全消除模型语义幻觉。Dentalbook 只证明引用与来源的完整性。

## 5. 不变量

| 编号 | 不变量 |
|---|---|
| P-1 | 无 UI 的 MCP 客户端也能完成全部核心业务。 |
| P-2 | 业务事务由领域应用服务编排，不依赖模型维持跨工具一致性。 |
| P-3 | 所有写入拿到真实回执后才能显示成功。 |
| P-4 | 题录、PDF 和原句证明是不同状态，不得合并表达。 |
| P-5 | 高风险作者合并、关系覆盖和永久删除必须服务端确认。 |
| P-6 | 中心共享资产与个人本地资产有明确所有权和审计边界。 |
| P-7 | Skills 只定义可观察流程，不能承担授权、事务或数据真实性。 |

## 6. 当前里程碑的完成定义

- 文档和 ADR 足以指导下一阶段实现。
- npm workspace 能构建、测试和验证。
- 用户 MCP 提供共享列表、统计、本地上传、中心下载与真实 library MCP App。
- Web 通过短期会话显示真实共享列表、PDF 下载状态与基础作者索引。
- 用户 MCP 提供作者列表与作者详情的结构化读取工具。
- 管理员 MCP 单独提供 Fetch 与共享统计，不混入医生工具面。
- UI probe 能被 MCP 客户端读取为 `text/html;profile=mcp-app`。
- 共享文献库 UI 显示真实业务状态；其余四个业务 UI 入口继续诚实显示未实现。
- 插件与六个 Skills 通过官方校验器。
